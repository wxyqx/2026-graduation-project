# 数据库字段说明文档（数据字典）

> 数据库：MySQL（建议 8.0，字符集 utf8mb4）
> 建表脚本：crebas.sql（由 ATS.pdm 生成，2026-09-08 定稿）
> 枚举取值：阶段 current_stage / 结果 result / 全局 overall_status 见文末枚举字典

## Candidate 表（候选人）

表注释：存储投递简历的候选人基础信息

| 字段名 | 数据类型 | 约束 | 中文名称 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| ID | INT | 主键，NOT NULL，自增 | 候选人编号 | 候选人唯一标识，插入时无需传值 |
| create_time | DATETIME | - | 创建时间 | 候选人记录创建时间 |
| name | VARCHAR(255) | - | 姓名 | 候选人姓名 |
| remark | VARCHAR(500) | - | 备注 | 备注（来源渠道、特殊情况等） |

## Position 表（岗位）

表注释：存储公司发布的招聘岗位信息

| 字段名 | 数据类型 | 约束 | 中文名称 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| ID | INT | 主键，NOT NULL，自增 | 岗位编号 | 岗位唯一标识，插入时无需传值 |
| position_name | VARCHAR(100) | - | 岗位名称 | 职位名称（如：Java高级工程师） |
| owner | VARCHAR(100) | - | 负责人 | 岗位负责人（招聘负责人/HR） |
| position_requirements | VARCHAR(2000) | - | 岗位要求 | 职位描述/JD（任职要求、职责） |
| is_hidden | TINYINT | DEFAULT 0 | 暂不招 | 1=暂不招（隐藏）：该岗位及其名下全部投递不再出现在统计、下拉、列表、AI 筛选与导出中；数据保留，改回 0 即恢复（v3.9 新增） |

| resume_submit_time | DATETIME | - | 简历提交时间 | 候选人提交简历的时间 |
| resume_result | VARCHAR(20) | - | 简历筛选结果 | HR 审核简历的筛选结果 |
| phone_time | DATETIME | - | 电话沟通时间 | 电话初筛进行时间 |
| phone_result | VARCHAR(20) | - | 电话沟通结果 | 电话初筛评估结果 |
| test_time | DATETIME | - | 笔试时间 | 笔试/测评进行时间 |
| test_result | VARCHAR(20) | - | 笔试结果 | 笔试/测评评分结果 |
| pro_time | DATETIME | - | 专业面时间 | 专业/技术面试时间 |
| pro_result | VARCHAR(20) | - | 专业面结果 | 技术/专业面试评估结果 |
| hr_time | DATETIME | - | HR面时间 | HR 面试时间 |
| hr_result | VARCHAR(20) | - | HR面结果 | HR 面试评估结果 |
| final_time | DATETIME | - | 终面时间 | 高管终面时间 |
| final_result | VARCHAR(20) | - | 终面结果 | 高管终面评估结果 |
| current_stage | VARCHAR(20) | - | 当前阶段 | 候选人当前所处阶段，初始为 ai |
| overall_status | VARCHAR(20) | NOT NULL，DEFAULT 'pending' | 全局状态 | pending 进行中 / pass 已录用 / fail 已淘汰；被淘汰或录用后撤回时自动恢复 pending |

| resume_reason | TEXT | - | 简历筛选原因 | 简历筛选为什么通过/淘汰（人工填写，v3.14 新增） |

| test_reason | TEXT | - | 笔试原因 | 笔试为什么通过/淘汰（人工填写，v3.14 新增） |
| pro_reason | TEXT | - | 专业面原因 | 专业面为什么通过/淘汰（人工填写，v3.14 新增） |
| pro_evaluation | TEXT | - | 专业面面试评价 | 专业面环节的面试评价（人工填写，可用 AI 生成后润色，v3.14 新增） |

## User 表（用户）

表注释：仅用于登录、注册和 AI API 配置管理（自用单用户场景，无角色权限设计）

| 字段名 | 数据类型 | 约束 | 中文名称 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| ID | INT | 主键，NOT NULL，自增 | 用户编号 | 用户唯一标识 |
| username | VARCHAR(50) | NOT NULL，唯一 | 用户名 | 登录用户名 |
| password_hash | VARCHAR(100) | NOT NULL | 密码哈希 | 登录密码的哈希值（不存明文） |
| create_time | DATETIME | - | 创建时间 | 用户创建时间 |

## AI_API_Config 表（AI接口配置）

表注释：存储 AI 筛选使用的 LLM API 配置，可添加多个并启用多个，批量筛选时在启用的配置间轮询分流

| 字段名 | 数据类型 | 约束 | 中文名称 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| ID | INT | 主键，NOT NULL，自增 | 配置编号 | 配置唯一标识 |
| name | VARCHAR(50) | NOT NULL | 配置名称 | 配置显示名（如"GLM免费版"） |
| base_url | VARCHAR(255) | NOT NULL | 接口地址 | LLM API 的接口地址 |
| api_key | VARCHAR(255) | NOT NULL | 密钥 | API 密钥（自用系统明文存储） |
| model | VARCHAR(100) | NOT NULL | 模型名 | 调用的模型名称 |
| is_enabled | TINYINT | DEFAULT 0 | 启用 | 1=启用；可多个同时启用 |
| User_ID | INT | 外键→User.ID，NOT NULL | 所属用户 | 该配置归属的用户 |

## App_Setting 表（系统设置）

表注释：存储系统设置项，以键值对形式保存（v3.4 新增）。目前用于保存「AI 筛选提示词」（setting_key = 'ai_prompt'）

| 字段名 | 数据类型 | 约束 | 中文名称 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| ID | INT | 主键，NOT NULL，自增 | 设置编号 | 设置记录唯一标识 |
| User_ID | INT | 外键→User.ID，NOT NULL | 所属用户 | 该设置归属的用户（每人一份提示词） |
| setting_key | VARCHAR(50) | NOT NULL | 设置项 | 设置项名称，如 ai_prompt |
| setting_value | TEXT | - | 设置值 | 设置内容（AI 筛选提示词的规则部分） |
| update_time | DATETIME | - | 更新时间 | 最近一次修改时间 |

> 说明：(User_ID, setting_key) 建唯一索引 UK_User_Key，保证同一用户同一设置项只有一条。
> 回答格式（必须输出 JSON、result 只能 pass/fail）由程序锁定，**不存表、不可改**，仅筛选规则可自定义。

## 约束与索引

| 名称 | 类型 | 字段 | 说明 |
| :--- | :--- | :--- | :--- |
| 各表主键 | 主键 | ID | 六表主键均为自增 INT |
| AK_Username_UK | 唯一索引 | User.username | 用户名不可重复 |
| FK_Relationship_1 | 外键 | Application.Pos_ID → Position.ID | 删除/更新受限（restrict） |
| FK_Relationship_2 | 外键 | Application.Can_ID → Candidate.ID | 删除/更新受限（restrict）；候选人删除由**应用层先删其名下投递**实现级联（开发计划 v3.2），数据库外键保持 restrict |
| FK_Relationship_3 | 外键 | AI_API_Config.User_ID → User.ID | 删除/更新受限（restrict） |
| FK_Relationship_4 | 外键 | App_Setting.User_ID → User.ID | 删除/更新受限（restrict），v3.4 新增 |
| UK_User_Key | 唯一索引 | (App_Setting.User_ID, setting_key) | 同一用户同一设置项只有一条 |
| UK_Can_Pos | 唯一索引 | (Can_ID, Pos_ID) | 同一候选人对同一岗位只能有一条投递记录 |

## 枚举字典

**current_stage（当前阶段，按流程顺序）**

| 值 | 含义 |
| :--- | :--- |
| ai | AI筛选（初始阶段） |
| resume | 简历筛选 |
| phone | 电话沟通 |
| test | 笔试 |
| pro | 专业面 |
| hr | HR面 |
| final | 终面 |

**result（各阶段结果，ai_result ~ final_result 共用）**

| 值 | 含义 |
| :--- | :--- |
| pass | 通过，推进到下一阶段 |
| fail | 淘汰，流程终止 |

**overall_status（全局状态）**

| 值 | 含义 |
| :--- | :--- |
| pending | 进行中 |
| pass | 已录用（流程结束） |
| fail | 已淘汰（流程终止，撤回可复活） |
